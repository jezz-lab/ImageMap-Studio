# ▱ ImageMap Studio

A simple browser-based tool for creating polygon coordinates for HTML image maps.

<a href="https://jezz-lab.github.io/ImageMap-Studio/" target="_blank">🌐 Live Demo</a>

## Features

* Upload or drag & drop an image
* Create polygon points by clicking
* Move and delete points
* Zoom in and out
* Automatically generate HTML `<area>` coordinates
* Copy the generated HTML

## How to Use

1. Open ImageMap Studio.
2. Upload an image.
3. Click on the image to create points.
4. Close the polygon.
5. Copy the generated HTML.

No installation or server is required.

## Run Locally

Download or clone the repository and open `index.html` in your web browser.
